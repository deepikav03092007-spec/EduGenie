# EduGenie – Generative AI Learning Assistant

EduGenie is a Generative AI-powered learning assistant designed to help students learn concepts, practice questions, summarize study material, and create personalized learning paths.

## Features

### 💬 Q&A
Ask questions on educational topics and receive AI-generated answers.

### 💡 Explain
Get difficult concepts explained in a simple and easy-to-understand way.

### 🧠 Quiz
Generate quizzes for practice and self-assessment.

### 📝 Summary
Summarize notes or study material into concise and useful content.

### 🗺️ Learning Path
Generate a personalized learning path for a selected topic.
